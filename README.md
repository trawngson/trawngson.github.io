# truongson.me

The portfolio of Nguyen Truong Son, served by GitHub Pages at <https://truongson.me>.

It is a plain static site: HTML generated by a small Node script, one stylesheet,
and one motion script. There is no framework and no package install.

## Editing

All text, projects and images are listed in [`src/content.mjs`](src/content.mjs).
Change it, then rebuild and check the pages:

```bash
node scripts/build.mjs    # writes index.html, works/**, contact/, 404.html
node scripts/verify.mjs   # checks links, assets and metadata
python3 -m http.server    # preview at http://localhost:8000
```

Commit the generated HTML along with your changes; GitHub Pages serves the files as they are.

| Path | What it is |
| --- | --- |
| `src/content.mjs` | Every word on the site and the project list |
| `src/templates.mjs` | Page and component markup |
| `src/icons.mjs` | The isometric section icons |
| `assets/css/site.css` | Design tokens, layout and the animated project covers |
| `assets/js/main.js` | Motion: GSAP, ScrollTrigger, SplitText, Flip, Lenis and Matter.js |
| `assets/img/` | Images (WebP and AVIF) |
| `works/aware-bin/viewer.html` | The smart bin's offline 3D viewer |

### Adding a project

Add an entry to `projects` in `src/content.mjs`. A project needs a `slug`, text
fields, and a `cover`: `phones`, `object` or `image` for pictures, `browser` for a
website screenshot, or one of the animated `tool-*` covers. Rebuild, and the
works page, filters and project page appear automatically.

## Motion and accessibility

Animation libraries load from jsDelivr at pinned versions. If they fail to load,
or the visitor prefers reduced motion, every page still shows all of its content.
Page-to-page morphs use the browser's View Transitions API where supported.
